# Context Graph Command Center

Production-quality static demo for an AI-inspired knowledge-graph operations console, designed for public deployment on Cloudflare Pages.

## What is included

- React 19 + Vite 8 + TypeScript
- Tailwind CSS 4
- Sigma.js + Graphology interactive graph
- Zustand state management
- Recharts trend visualizations
- Lucide React iconography
- ESLint + Prettier
- Static, version-controlled demo data
- Cloudflare Pages configuration (`wrangler.toml`)
- GitHub Actions validation workflow (`.github/workflows/validate.yml`)

The current demo is fully static after build and does **not** require a backend, API keys, credentials, or environment variables.

## Quick start

```bash
npm install
npm run dev
```

Open the local Vite app shown in the terminal.

## Validation

```bash
npm run lint
npm run build
```

Production output is written to:

```bash
dist/
```

## Cloudflare Pages

Use the repository root as the project root with:

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node version:** `20` or later

Recommended Git integration flow:

- Production deploys from `main`
- Preview deploys from feature branches and pull requests
- GitHub remains the source of truth for every deployment

## Demo behavior

The app presents a polished intelligence-console experience around a synthetic context graph:

- graph construction events
- agent activity stream
- interactive community / cluster filtering
- evidence-backed paths
- graph querying presets
- live-style operational metrics
- searchable node directory

## Demo data policy

The dashboard uses synthetic and imputed fields where public inbound data is incomplete.

- Public-data provenance is shown in the UI.
- Degraded-source states remain labeled.
- Carrier-delay and turnaround indicators are explicitly framed as proxies.
- The app does **not** claim access to crew, gate, maintenance, passenger, or safety systems.

## Repository notes

- `frontend/` contains the Vite application.
- `dist/` is generated by the frontend build and is the Cloudflare Pages artifact.
- `backend/`, `docs/`, and `shared/` are retained as supporting research and data-model artifacts from earlier repository phases.

## Optional environment variables

None are required for the demo. If future integrations are added, use environment variables only for optional configuration.
